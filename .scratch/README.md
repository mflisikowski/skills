# Local work tracker

Create one directory per feature or effort. Store its spec in `<feature>/spec.md` and each implementation ticket in `<feature>/issues/NN-<slug>.md`.

Keep specs, decisions, tickets, and completion evidence in Git. Put generated measurements or screenshots in `<feature>/artifacts/`, which is ignored.

Tracker behavior and triage roles are defined in `docs/agents/issue-tracker.md` and `docs/agents/triage-labels.md`.
